## (b) Perilaku UX yang layak dipertahankan saat migrasi Next.js

1. **Shell mobile `max-w-md` + bottom nav** — target produk mobile-first/PWA; pola navigasi jempol ini fondasi P0.3–P0.4.
2. **Dua mode: Latihan (feedback langsung per soal) vs Simulasi (countdown 90:00, tanpa bocoran kunci)** — inti core loop Practice vs Tryout (Fase 6 vs Fase 9).
3. **Peta nomor + tandai ragu-ragu** — perilaku ujian standar; mengurangi kecemasan dan soal terlewat. Calon P9.5–P9.6.
4. **Konfirmasi sebelum kumpul / keluar / hapus (`ConfirmSheet`)** — mencegah progres hilang karena salah sentuh di layar kecil.
5. **Pembahasan per soal + filter "Salah"** — embrio Mistake Review (P7.10); alasan belajar utama pengguna membuka hasil.
6. **Bedah skor per mapel + label grade ("Mantul!", "Gas lagi")** — embrio Mastery Profile/Dashboard (P8.6–P8.8); `InlineDataBar` reusable untuk peta mastery.
7. **Toggle gelap/terang (default gelap) + hormat `prefers-reduced-motion`** — aksesibilitas; jangan regressi saat port tema global (P0.3).
8. **Riwayat attempt + skor terbaik + animasi `CountUp`** — motivasi retensi; nanti datanya dari Neon, polanya tetap.
9. **Acak urutan soal tiap mulai + timer auto-kumpul saat waktu habis** — kewajaran sesi; nanti pengacakan/penguncian set soal pindah ke server (P9.2).
10. **Target sentuh ≥44px, ikon Lucide, tipografi display untuk angka** — standar sentuh mobile; bawa ke design token Next.js.

## (c) Kode prototype-only yang harus dipensiunkan

1. **Kunci jawaban + pembahasan dikirim ke browser** (`questions.ts: answer`, dibaca langsung di `Exam.tsx`/`Result.tsx`) — melanggar aturan `AGENTS.md` ("Sending correct answers in active exam payloads"); migrasi ke validasi jawaban server-side (P6.2–P6.4, P9.9).
2. **localStorage sebagai satu-satunya penyimpanan** (`store.attempts`, cap 50, tanpa akun) — data hilang saat ganti HP/hapus cache, tanpa multi-device; diganti Neon via repository/service (Fase 2, P6.5).
3. **Bank soal statis di-bundle** (60 soal hardcoded, opsi tuple-5 teks polos) — tak ada taksonomi resmi, skema rich-content, atau review; diganti CMS + `ContentBlock` tervalidasi Zod (Fase 1, 3, 4).
4. **Skoring client-side** (`scoreOf` di `App.tsx`) — klien tak dipercaya (`ARCHITECTURE.md`); skor resmi dihitung server (P6.4, P9.9).
5. **Auth semu (nama bebas tanpa login, tanpa role)** — tak ada proteksi rute/CMS; diganti auth sesi server + role student/editor/reviewer/admin (P2.8–P2.10).
6. **Router state-machine in-memory (keluar = hangus, tanpa resume/autosave)** — diganti rute App Router + sesi persisten + autosave (P6.11, P9.7–P9.8).
7. **Bootstrap Vite-only** (`vite.config.ts`, `vercel.json` → `framework: vite`, `types: vite/client`) — dicabut setelah shell Next.js berdiri (P0.2, P0.7).
8. **`uid()` acak klien + tanpa validasi skema runtime** — diganti id/validasi server (Zod, P3.2).
9. **Meta mapel hardcoded di UI** (`SUBJECTS`/`SUBJECT_IDS` diimpor komponen) — arsitektur wajib multi-subject via taksonomi DB, tanpa hardcode ke core engine (`AGENTS.md`, P1–P2).
